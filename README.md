# Employee Attrition Analysis

## Overview

This project analyzes employee attrition data to identify patterns and factors that contribute to employee turnover. The analysis is performed using Python, Pandas, Matplotlib, and Seaborn.

## Objective

The goal of this project is to understand why employees leave an organization and discover trends related to age, salary, department, job role, overtime, and years of experience.

## Dataset

The dataset contains employee information such as:

* Age
* Department
* Job Role
* Monthly Income
* Gender
* Education
* Years at Company
* Overtime
* Attrition Status

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights
6. Conclusion

## Key Analysis Performed

* Employee Attrition Distribution
* Department-wise Attrition Analysis
* Salary vs Attrition
* Age Group Analysis
* Job Role Analysis
* Overtime Impact on Attrition
* Correlation Analysis

## Business Insights

* Identified departments with higher employee turnover.
* Analyzed the relationship between salary and attrition.
* Examined attrition trends across different age groups.
* Evaluated the impact of overtime on employee retention.
* Identified job roles with higher attrition rates.

## Conclusion

The analysis provides valuable insights into employee turnover patterns and highlights factors that may influence attrition. These findings can help organizations improve employee retention strategies and workforce planning.
